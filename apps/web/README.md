# RABmate AI — Web

Frontend Next.js (App Router). Setup, perintah, dan troubleshooting ada di
[../../docs/LOCAL_DEVELOPMENT.md](../../docs/LOCAL_DEVELOPMENT.md).

```powershell
npm run dev        # http://localhost:3000 (butuh API di 127.0.0.1:8000)
npm test           # Vitest
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
npm run build      # build produksi
```

Catatan versi: Next.js 16.4 berbeda dari versi lama — baca panduan di
`node_modules/next/dist/docs/` sebelum memakai API baru (lihat `AGENTS.md`).
